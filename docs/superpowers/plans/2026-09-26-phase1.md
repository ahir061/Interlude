# Interlude Phase 1 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans, task by task, with meaningful tests and milestone commits.

**Goal:** Execute a real Bengali MP4 through safe semantic ad selection and browser content → ad → content.
**Architecture:** FastAPI plus one persistent MySQL job worker; modular media/providers/policy services; Next.js player.
**Tech Stack:** Python 3.11, Pydantic, SQLAlchemy, Alembic, MySQL, PySceneDetect, Silero, FFmpeg, Next.js/TypeScript.
**Spec:** `docs/PROJECT-Spec.md` and `docs/superpowers/specs/2026-09-26-phase1-design.md`.

## Global constraints
Never expose secrets. Existing LLM_*, DB_* and ASR_* names remain supported. No local Qwen, no PostgreSQL/vector/RAG. Uncertain means reject. Commit only verified milestones. Work in this repository on a feature branch; no push required.

## Review focus
Malformed provider timestamps must fail; frame-window failure must reject; restart must not strand jobs; actual creative duration must drive pacing; seeking/repeated timeupdate events must not duplicate ads.

### Task 1: Contracts and configuration
Files: `pyproject.toml`, `apps/api/interlude/config.py`, `domain.py`, `tests/test_contracts.py`.
Produces Settings, Scene, Transcript, BreakCandidate, SceneSemantics, Brand, Creative, BrandMatch, BreakDecision, AnalysisResult, AnalysisJob. Tests reject invalid intervals, unsafe IDs and invalid semantic scores.
- [x] Write and run contract tests (initially fail), implement models/settings, run pytest, commit core milestone.

### Task 2: Deterministic decision services
Files: `services/candidates.py`, `brands.py`, `policy.py`, `manifest.py`, `tests/test_engine.py`.
Consumes canonical models. Produces CandidateService.generate(scenes, transcript, vad, duration), BrandMatchingService.evaluate(semantics, brands), WhereService.score(candidate, semantics), PacingService.evaluate(timestamp, ad_duration, accepted, duration), ManifestService.write(result, output_dir).
- [x] Write required safety/ninth-brand/pacing/schema tests, observe failure, implement, run pytest, commit.

### Task 3: Media and external providers
Files: `services/media.py`, `speech.py`, `providers/asr.py`, `semantic.py`, `services/creatives.py`, `tests/test_providers.py`, `test_media.py`.
Produces MediaProbeService.probe(path), SceneDetectionService.detect(path), VadService.detect(audio), AsrProvider.transcribe(audio), SemanticVideoProvider.analyze(window, transcript, vocabulary), CreativeService.ensure(brands). Use CPU Silero, real FFmpeg fixture; mocked HTTP only for bounded failure tests.
- [x] Install local dependencies; write failure and real-media tests; implement; verify CPU VAD and generated MP4; commit.

### Task 4: MySQL, worker and API
Files: `db.py`, `repository.py`, `pipeline.py`, `worker.py`, `main.py`, `migrations/`, `tests/test_pipeline.py`.
Consumes all services, persists each stage and canonical result. Produces upload/analyze/status/analysis/debug/media/brand/health/readiness endpoints.
- [x] Test state transitions and pipeline failure handling; implement schema and migration; migrate actual hosted MySQL without printing credentials; verify API/upload worker; commit.

### Task 5: Plain web player

Consumes analysis ad_breaks and debug decisions. Produces upload, job polling, JSON and functional insertion/resume.
